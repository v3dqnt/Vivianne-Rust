# shell/src/characters

The mini characters (Kenney, CC0) that can stand for agents. `render.rs` is a small software renderer for their skinned glTF models and animations; `mod.rs` draws a loop once, keeps it as PNGs in `~/.viv/characters/`, and offers `CharacterView` to play it. The models are in `../../assets/characters/`. Settings → Characters shows them all.
