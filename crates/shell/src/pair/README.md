# shell/src/pair

Working on a project with a partner on another machine (the connection and its logic are in
`vivianne-multiplayer`).

- `projects.rs`: which projects are paired and with whom, from `~/.viv/agent/projects.json`, as the connection asks.
- `view.rs`: the Pair page: how to pair the open project; once paired, the connection, the chat between the two
  people, and what each side's agent has been doing.
