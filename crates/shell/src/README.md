# shell/src

- `main.rs`: starts the tokio runtime, builds the agent session from the environment, opens the window.
- `theme.rs`: colour, radius and spacing tokens from the old component library.
- `demo.rs`: offline provider (`VIV_DEMO=1`) so the window can be run and checked without a key.
- `chat/`: the chat screen.
- `bin/`: throwaway spike binaries.
