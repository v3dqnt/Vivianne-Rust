Per-run change recording. `git` (private snapshots, tree diffs, ignore checks), `capture` (whole-file copies around file-tool edits), `compare` (line comparison with a deadline), `numstat` and `paths` (parsing and display forms), `recorder` (one conversation's runs and summaries), `types`, and `tests` against real repositories. Deviations from the original: SHA-256 names for copies, summaries keyed by turn (no session event log), and a comparison deadline checked after the diff.
